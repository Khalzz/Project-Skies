# Pankarta Software

This is a game engine made in Rust with SDL2 and with 3D implementations with WGPU, this is the starting of a journey, the pankarta studio's main hammer, i will make this bigger and better so making games here is fun, and interesting.

The main engine is divided on a: App: the core element that defines the name of the screen, 3D surfaces and more GameStates: the elements who are rendered inside a main loop, these elements are the playable stuff that the player will see
